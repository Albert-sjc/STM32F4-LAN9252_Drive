本 ReadMe 文件说明 LAN9252-PIC32 SDK 的文件夹结构。

本示例 SDK 源代码需要使用 EtherCAT.org 提供的 Slave Stack Code 5.11 才能运行。
有关如何将 LAN9252 SDK 与 Beckhoff 的 EtherCAT® 从站协议栈代码集成，请参阅应用说明
“Integrating Microchip's LAN9252 SDK with Beckhoff's EtherCAT® SSC”
（将 Microchip 的 LAN9252 SDK 与 Beckhoff 的 EtherCAT® SSC 集成）。

文件说明：
===============
9252_HW.c 和 9252_HW.h——硬件抽象层接口，与平台无关。
这些文件要求使用“Microchip_LAN9252_SSC_Config.xml”生成 SSC 代码。

-----------------------------------------------------------------------------------
===============
SPI 驱动：
===============
SPIDriver.c 和 SPIDriver.h——包含访问 LAN9252 的 SPI 例程，与平台无关。
-----------------------------------------------------------------------------------

===============
PIC32SPIDriver——此文件夹专用于 PIC32MX795F512L 的 SPI 模块。如果使用其他型号的 PIC，
                 请相应修改。
需要针对其他 SoC 修改的函数如下。
		/*******************************************************************************
		函数：
			void SPIOpen(void)
		摘要：
			此函数配置 SoC 的 SPI 模块。

		说明：
			此函数配置 SoC 的 SPI 模块。

		/*******************************************************************************
		函数：
			void SPIRead(void)
		摘要：
			此函数读取一个字节。

		/*******************************************************************************
		函数：
			void SPIOpen(void)
		摘要：
			此函数配置 SoC 的 SPI 模块。
-----------------------------------------------------------------------------------
===============
HBI 驱动：
===============
PMPDriver.c 和 PMPDriver.h——包含通过 HBI 访问 LAN9252 的例程，与平台无关。

需要针对其他 SoC 修改的函数如下。
===============
PIC32PMPDriver——此文件夹专用于 PIC32MX795F512L 的 HBI（PMP）模块。如果使用其他型号的 PIC，
                 请相应修改。
		/*******************************************************************************
		函数：
			void PMPOpen(PMPMode pmpmode, RWType rwtype, Polarity pl)
		摘要：
			此函数配置 SoC 的 PMP（主机总线接口）模块。

		/*******************************************************************************
		函数：
			UINT32 PMPReadDWord (UINT16 Address)
		摘要：
			此函数从 LAN9252 CSR 寄存器读取 4 字节数据。

		/*******************************************************************************
		函数：
			void PMPWriteDWord (UINT16 Address, UINT32 Val)
		摘要：
			此函数向 LAN9252 CSR 寄存器的相应地址写入 4 字节数据。
-----------------------------------------------------------------------------------

===============
PICHW.c：包含 IRQ、SYNC0、SYNC1 和定时器中断例程，以及配置和控制中断的专用函数调用。
此文件专用于 PIC32MX795F512L 和 LAN9252 评估板。
需要针对其他 SoC 修改的函数如下。

		/*******************************************************************************
		函数：
			void PDI_Init_SYNC_Interrupts(void)

		说明：
			此函数配置并启用 SYNC0 和 SYNC1 中断，与平台相关。
			INIT_SYNCx_INT 是用于配置外部中断的宏，ENABLE_SYNCx_INT 是用于启用
			对应线路中断的宏。

		/*******************************************************************************
		函数：
			void PDI_Restore_Global_Interrupt(UINT32 Int_sts)

		说明：
		此例程将内核恢复到先前的中断处理状态。

		参数：
		Int_sts      - 先前的中断处理状态。

		示例：
		<code>
		unsigned int intStatus;

		intStatus = PDI_Disable_Global_Interrupt();

		// ... 应用程序代码

		PDI_Restore_Global_Interrupt(intStatus);
		</code>

		/*******************************************************************************
		函数：
		 void PDI_Enable_Global_interrupt(void)

		说明：
		此例程使内核能够处理任何待处理的中断请求。

		前置条件：
		需要将系统配置为使用中断（如果使用 IRQ、SYNC0 和 SYNC1）。

		/*****************************************************************************
		函数：
		UINT16 PDI_GetTimer(void)

		摘要：
		获取当前 1 ms 定时器的值。
		说明：
		此例程获取当前 1 ms 定时器的值。

		/*******************************************************************************
		函数：
		void PDI_ClearTimer(void)

		说明：
		此例程清除当前 1 ms 定时器的值。

		/*******************************************************************************
		函数：
		void PDI_Timer_Interrupt(void)

		说明：
		此函数配置并启用周期为 1 ms 的 TIMER 中断。

		/*******************************************************************************
		函数：
		void PDI_IRQ_Interrupt(void)

		说明：
		此函数配置并启用 IRQ 中断。

		/*******************************************************************************
		函数：
		void HW_SetLed(UINT8 RunLed,UINT8 ErrLed)

		说明：
		LAN9252 不支持错误 LED。因此，如需此功能，必须由 PDI SoC 启用。

		参数：
		RunLed  - 未使用。该 LED 将由 LAN9252 设置。
		ErrLed  - 1：亮，0：灭。

		/*******************************************************************************
		函数：
		void __ISR(_EXTERNAL_0_VECTOR, ipl7srs) ExtInterruptHandler(void)

		摘要：
		EtherCAT 从站控制器所产生 PDI 中断的中断服务程序。

		/*******************************************************************************
		函数：
		void __ISR(_EXTERNAL_1_VECTOR, ipl5) Sync0Isr(void)

		摘要：
		SYNC0 中断的中断服务程序。

		/*******************************************************************************
		函数：
		void __ISR(_EXTERNAL_2_VECTOR, ipl4) Sync1Isr(void)


		摘要：
		SYNC1 中断的中断服务程序。

		/*******************************************************************************
		函数：
		void __ISR(_TIMER_5_VECTOR,IPL3AUTO) _TIMER5_HANDLER(void)

		摘要：
		TIMER5 中断的中断服务程序。
-----------------------------------------------------------------------------------
===============
Microchip_LAN9252_SSC_Config.xml——SSC 工具的输入 XML 文件。该文件包含 LAN9252 的专用配置，
并且与平台无关。
-----------------------------------------------------------------------------------
